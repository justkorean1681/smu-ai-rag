- 주제: ISMS-P 인증 기준 관련 지침 안내서 내용을 바탕으로 ISMS-P 전문가 역할을 수행하도록 구현

Day 3: 테이블 데이터 조회 시스템(Text2SQL) 구축 
- 주제: 한국 인터넷 진흥원의 ISMS-PIMS 연도별 결함 현황과 ISMS-P 관리체계 세부 점검 항목 데이터를 활용하여 인증 기준별 결함 통계 데이터를 분석하고, 어떤 분야에서 결함이 많이 발생하는지 체계적으로 모니터링하는 환경 구축
- 사용한 데이터
    - isms_items.csv: ISMS-P 인증 기준 항목별 상세 내용 및 주요 확인 사항 매핑 정보
    - isms_defects.csv: 각 통제 영역별 결함 발생 건수 통계 데이터
